# Tangram Offline Releases

這個 repo 只放 **Tangram Offline** 的 Windows 執行檔，不含原始碼。

- 下載：到 [Releases](../../releases/latest) 下載 `TangramOffline.exe`，可改名為 `Tangram Offline.exe`。
- 驗證：同一個 Release 附有 `TangramOffline.exe.sha256`。
- 自動更新：1.1.0 以後的版本啟動約 10 秒後會檢查這裡的最新 Release，有新版會在系統匣通知，點一下就能更新；筆記資料（`data/`）不會被動到。
- 從 1.0.0 升級：1.0.0 沒有更新功能，請先從系統匣結束 Tangram Offline，再手動把執行檔換成新版一次。
